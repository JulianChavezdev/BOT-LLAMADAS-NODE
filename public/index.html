FAQ

Lo basico para decidir rapido.

Necesito cambiar mi telefono?

No. Se configura Twilio para recibir o redirigir llamadas al bot.

Puede tomar pedidos reales?

Si. El flujo ya guarda pedidos, totales y cliente, y los muestra en cocina.

Que falta para produccion?

Base Postgres, deploy, variables reales, dominio y prueba completa de llamada.

Se puede adaptar a otro restaurante?

Si. El sistema ya tiene tenant, menu editable y configuracion de negocio.
